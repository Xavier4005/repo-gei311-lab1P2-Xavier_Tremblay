Premièrement, on crée un repo vide sur GitHub.
Deuxièmement, on entre la commande suivante : git remote add origin https://github.com/CamilleB222/repo-gei311-lab1P2-Camille_Barrette.git
Celle-ci permet de faire le lien avec le repo sur GitHub.
Troisièmement on entre la commande suivante : git push -u origin master
Celle-ci permet de push vers le repo GitHub.
